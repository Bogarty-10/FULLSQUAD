# FULLSQUAD
App de gestión de equipos deportivos amateurs. Proyecto Final DAM

## Descripción

FULLSQUAD es una aplicación destinada a la gestión de equipos deportivos amateurs, permitiendo a entrenadores y jugadores organizar partidos, eventos y asistencia.

## Funcionalidades

- Registro de usuarios
- Roles Entrenador y Jugador
- Gestión de partidos
- Confirmación de asistencia
- Calendario de eventos
- Gestión de jugadores
- Noticias del equipo

## Tecnologías utilizadas

- Android Studio
- Java
- SQLite
- Material Design
